01

RECOMMENDED · GUIDED FULL FLOW

Install with PowerShell ›_

Run these three lines in PowerShell 7 from a directory where you want the source checkout.

›_ PowerShell 7 3 COMMANDS · FULL SETUP
git clone https://github.com/samy6352/Cloud-lens-classic-November.git
cd Cloud-lens-classic-November
pwsh -File .\install.ps1

Requires Git, PowerShell 7, Python 3.11+ and Azure CLI with Bicep installed. The installer reviews approved inputs, checks consent and preflight, previews changes, then asks for explicit DEPLOY confirmation before provisioning and publishing code. There is no verified hosted ZIP download.

02

ALTERNATIVE · INFRASTRUCTURE ONLY

Start in Azure portal ↗

Review and deploy the subscription-scope infrastructure template in Azure. This creates chargeable resources; it does not publish application code or grant Entra consent.

Deploy to Azure →

Opens Azure portal in this tab. Sign in with your Azure account to review the custom deployment; nothing is provisioned until you approve it in Azure. Review the template JSON. Prefer the guided script for the full flow: the portal does not run the installer's consent, preflight or What-If gates. Continue with the deployment guide for code publication and acceptance checks.

DEPLOY WITH INTENTION

A few things to have ready

No shortcuts around permissions, consent or cost.

  • Identity & consentObtain a preapproved, customer-owned single-tenant public-client Entra application, delegated ARM consent and the final HTTPS callback https://cloudlens-web-<suffix>.azurewebsites.net/auth/callback.
  • Subscription & capacityConfirm subscription permissions, approved regions and SKUs, AI model quota and capacity, network ranges and resource names. No automatic consent or quota/region bypasses.
  • Verify the full experienceProvisioning is not acceptance: verify sign-in, user RBAC, ingestion and a real AI question. Dashboard and API access remain authenticated.
